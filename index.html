About

I am an engineer working at the intersection of full-stack web development, agentic AI systems, and cybersecurity. Currently pursuing my Master of Computer Applications (MCA) at Dayananda Sagar University, Bengaluru (CGPA 8.27), my work centers on building reliable production services that combine backend rigor with next-generation generative AI.

Recently, at Vortex IQ (London, Remote), I engineered high-throughput onboarding flows handling 500+ concurrent registrations, architected 12+ RESTful APIs, and eliminated N+1 database queries through aggressive query optimization. In my own systems like CampusProjects.tech, I designed idempotent payment engines with PostgreSQL row-level locks and zero-leak code delivery via custom GitHub Apps with RS256 signed JWT tokens.

In generative AI, I specialize in Model Context Protocol (MCP), LangGraph multi-agent workflows, and hybrid RAG systems (DenseNet121 + BAAI/bge-m3 + BM25 + CrossEncoder rerankers). I co-invented a published Indian patent for an adaptive Bloom's Taxonomy cognitive assessment engine.

My background in security earned me the Karnataka State Gold Medal in Cyber Security at IndiaSkills 2024 and Cisco CCST Networking certification. When I'm not writing APIs or fine-tuning retrieval pipelines, you'll find me solving problems on LeetCode (80+ solved), mentoring peers in hands-on security labs, or experimenting with autonomous agent swarms.
